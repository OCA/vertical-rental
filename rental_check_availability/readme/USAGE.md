To use this module, you need to:

1.  Go to Rental Orders and create a new one.
2.  Add a product available for being rented out in sale order line.
3.  If there is not enough stock on hand to fullfil the order and
    possible concurrent ones the sale order line will be colorized.
    Yellow marks that there are concurrent quotations and red indicates
    concurrent orders.
4.  To check the concurrent order for a critical sale order line just
    click on the inline button being displayed in the sale order line.
